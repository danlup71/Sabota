# Welcome to the Sabota Contributing Guide

First of all, thank you for taking the time to contribute. ✨

Please read our [Code of Conduct](./CODE_OF_CONDUCT.md) to help keep the project welcoming, respectful, and enjoyable for everyone.

## Current Status

Sabota is still very much in the prototyping phase.

The architecture is taking shape and the tool is already usable, but there is still plenty of work to do. Expect rough edges, missing features, refactoring, and the occasional questionable design decision that future-me will have to explain.

Sabota is not trying to be Stryker. It started because I wanted a mutation testing tool for F# that matched the way I like to work and learn.

Building developer tools used to be a much bigger undertaking. Modern AI tooling helped me get started and explore ideas much faster, but the project is still very much a human-made work in progress.

## Ideas and Feedback

Issues, bug reports, suggestions, and discussions are always welcome.

I probably already have a long list of ideas myself, but time is finite, and good ideas often come from people using the tool in ways I never expected.

## Contributions

If you'd like to contribute, open an issue first so we can discuss the idea.

You're also welcome to fork the project and experiment with your own enhancements or features. Sabota is released under the [MIT License](./LICENSE).

## Keep in Mind

This is currently a small personal project maintained in spare time.

Please be patient, be kind, and don't take slow response times personally. I appreciate every contribution and every bit of feedback, even when I can't act on it immediately.
